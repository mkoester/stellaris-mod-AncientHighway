# Ancient Highway

A Stellaris mod (4.5.x, version 1.0.0): a ring of artificial, unclaimable systems around the
outside of the galaxy — built long ago for today's Fallen Empires — that every empire can reach
once it has studied and repaired the broken gate near its home. Inspired by the super highways
of X4.

*In other 4X games you settle on land but can still sail almost anywhere across the oceans. In
Stellaris there is no ocean: after a few decades most empires are landlocked, and an ally at war on
the far side of the galaxy is beyond help. The Ancient Highway is that ocean.*

**A first public version.** It works, but pacing, travel time and galaxy shapes beyond
elliptical are still being tuned. The store description lists what is open and what we are
watching. It is in `PUBLISHING.md`, together with the store links once they exist.

## Layout

- `ancient_highway/` — the mod (only this folder ships).
- `tools/gen.py` — generates the repetitive parts (gate pairs, ring builders, story fragments);
  `tools/check_script.py`, `tools/check_refs.py` — the checks run before each test.
- `docs/design.md` — the mechanics; `docs/lore.md` — the lore; `docs/console.md` — console test
  events; `docs/test-runs.md`, `docs/spike-runs.md` — what each in-game test found.
- `AGENTS.md` — status, how it works, and the engine's surprises, for whoever works on it.
- `PUBLISHING.md` — store texts and release checklist; `assets/` — the thumbnail's source.

Bugs and feedback: the ancient-highway forum on [our Discord](https://discord.gg/Vf8pqFXV6).

Unofficial fan project, not affiliated with Paradox Interactive.
