# The Ancient Highway's story (2026-11-19, docs/lore.md "How players learn it"): short pop-ups
# with one button, for human players only (AI countries see nothing and get no flags).
# - Three core chapters every player sees, whether they explore or research straight away:
#   ahw_story.1 the study (what it is, what now), .2 the first gate tech (by whom), .3 the first
#   ring node entered (why). Each once (country flag ahw_story_<key>).
# - Fragments (.10 picks one, .11-.22 and their twins): events/ahw_story_generated_events.txt,
#   written by tools/gen.py.
# - 2026-11-23 (user): each pop-up names its source in the event window's chain line - "The Shut
#   Doors" until the first ring node (flag ahw_story_road), "The Ancient Highway" from then on
#   (common/event_chains/ahw_event_chains.txt). An event's chain is fixed, so a pop-up that can
#   come on either side has a twin in the other chain (same texts; the caller fires both, the
#   trigger lets one through). Its camera button: event_target:ahw_story_at, set by the caller
#   (ahw_story_at_here / ahw_story_at_own_gate).
# Pictures are vanilla's, referenced by name.
namespace = ahw_story

	title = ahw_story.1.name

	picture = GFX_evt_alien_ruins
	location = event_target:ahw_story_at
	event_chain = ahw_shut_doors_chain
	is_triggered_only = yes

}
